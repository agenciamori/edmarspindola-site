Política de Privacidade

Última atualização: agosto de 2026. Este documento explica como os dados de quem visita ou entra em contato por este site são tratados.

Este site é mantido para divulgação do atendimento do Dr. Edmar Spindola, CRM 128649-SP / 20747-PA, RQE 39683, em Altamira, PA. O Dr. Edmar Spindola é o responsável pelo tratamento dos dados pessoais coletados por meio deste site.

2. Quais dados são coletados

Ao navegar ou entrar em contato por este site, os seguintes dados podem ser coletados:

  • Dados fornecidos voluntariamente ao iniciar uma conversa pelo WhatsApp, como nome e telefone
  • Dados de navegação, como páginas visitadas, tempo de permanência e origem do acesso

Este site não possui formulário de coleta de dados. O contato acontece exclusivamente pelo WhatsApp, fora do ambiente do site.

3. Finalidade do tratamento

Os dados coletados são usados para:

  • Responder a mensagens enviadas pelo WhatsApp e organizar agendamentos
  • Entender como o site é usado, para melhorar conteúdo e navegação
  • Cumprir obrigações legais e regulatórias aplicáveis ao atendimento médico

4. Cookies e ferramentas de análise

Este site pode usar cookies e ferramentas de análise de tráfego, como Google Analytics, para entender o comportamento de navegação de forma agregada. Esses dados não identificam a pessoa individualmente para fins de marketing.

5. Compartilhamento de dados

Os dados coletados não são vendidos ou compartilhados com terceiros para fins comerciais. Podem ser compartilhados apenas quando exigido por lei, ordem judicial ou para viabilizar o próprio atendimento, com a equipe médica envolvida no cuidado do paciente.

6. Armazenamento e segurança

Os dados são armazenados com medidas técnicas e administrativas razoáveis para evitar acesso não autorizado, perda ou uso indevido. Nenhum sistema é completamente livre de risco, mas buscamos seguir boas práticas de segurança da informação.

7. Seus direitos como titular de dados

De acordo com a Lei Geral de Proteção de Dados (LGPD, Lei nº 13.709/2018), você tem direito a:

  • Confirmar a existência de tratamento dos seus dados
  • Acessar os dados que temos sobre você
  • Corrigir dados incompletos, inexatos ou desatualizados
  • Solicitar a eliminação de dados tratados com o seu consentimento
  • Revogar o consentimento a qualquer momento

Para exercer qualquer um desses direitos, entre em contato pelo WhatsApp informado na página de Contato.
